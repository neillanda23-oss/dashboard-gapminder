# Dashboard Gapminder

Este proyecto consiste en un dashboard desarrollado en R con Shiny.

## Descripción
El dashboard permite visualizar información de la base de datos Gapminder mediante gráficos interactivos, tablas y filtros.

## Herramientas usadas
- R
- Shiny
- ggplot2
- plotly
- dplyr
- DT
- gapminder

## Funcionalidades
- Filtro por continente
- Filtro por año
- Gráfico interactivo
- Tabla de datos

## Archivo principal
El archivo principal del proyecto es `app.R`.
